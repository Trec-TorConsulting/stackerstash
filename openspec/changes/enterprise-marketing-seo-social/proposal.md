# Proposal

## Why

The current public website (`frontend/src/pages/MarketingPage.tsx` and `frontend/src/pages/ComingSoonPage.tsx`) misrepresents Stacker Stash as a pre-launch teaser and covers only a fraction of the shipped platform: unauthenticated traffic at `/` defaults to `ComingSoonPage` (`VITE_SITE_MODE = "coming_soon"`), `MarketingPage` omits major capabilities (Goldbacks, trading/collectible cards, local-first OCR/barcode identification, auto-sort, raw item grading & ROI, multi-source comp weighting & freshness, guided camera auto-crop/forensics, multi-vault switching, shared RBAC vaults, and offline coin-show PWA mode), and `#tiers` still renders an outdated 2-card grid instead of the 4-tier SaaS + self-hosted offering. Furthermore, `frontend/index.html` and `frontend/nginx.conf` lack foundational SEO metadata, crawlable static/prerendered HTML, `robots.txt`, `sitemap.xml`, structured data, Open Graph / Twitter Card tags, a `1200x630` social share image, enterprise trust/legal routes, and production Nginx security/caching headers.

## What Changes

- **Promote Full Marketing Experience to Root `/` (Breaking Public Root Change)**:
  - **BREAKING**: Change the default `VITE_SITE_MODE` fallback in `frontend/src/App.tsx` from `"coming_soon"` to `"marketing"` so unauthenticated visitors on `stackerstash.com/` land directly on the full marketing experience, while keeping `/coming-soon` (and `VITE_SITE_MODE=coming_soon` opt-in) functional.
  - Standardize public brand naming on **Stacker Stash** across all UI copy, `<title>`, SEO metadata, Open Graph/Twitter cards, JSON-LD, and legal pages, linking only the verified GitHub repository (`https://github.com/Trec-TorConsulting/stackerstash`) for social/open-source presence unless additional handles are added later.
- **Complete Platform Offerings, Assets & Tier Matrix (`public-marketing-website`)**:
  - Expand `MarketingPage` and dedicated public sub-pages (`/features`, `/pricing`, `/security`, `/privacy`, `/terms`) to showcase every production capability and asset class:
    - All supported assets: US & World Coins (including Ancient), Paper Banknotes & **Goldbacks** (`1/4`–`100` 24K fractional voluntary currency), Gold/Silver/Platinum/Palladium/Copper Bars & Rounds, **Trading & Collectible Cards** (Pokémon, MTG, Yu-Gi-Oh!, Disney Lorcana, One Piece, Sports), and **Certified Slabs** (PCGS, NGC, PMG, PCGS Banknote, CACG, ANACS, PSA, BGS, CGC, SGC, TAG).
    - Complete feature coverage: Guided Camera Capture (Circle/Rect/3:4 Card reticles, 1x–3x zoom, live focus/glare/clipping checks, auto-crop & tilt deskew, anti-pic-of-a-pic forensics), Local-First Identification Cascade (barcode/QR + RapidOCR + built-in static catalog -> text LLM -> composite Gemini Vision / self-hosted Ollama + Fast Bulk Mode), Background Auto-Sort Classification, Live 5-Metal Spot & Multi-Source Appraisal Engine (melt floor, Goldback exchange rate, PCGS/Greysheet/NumisMedia/Numista, PriceCharting/Scryfall/Pokémon TCG/PSA Pop/TAG DIG/BGS sub-grades, IQR outlier trimming, scheduled stale re-appraisal, valuation freshness & manual locks), Raw Grade Estimation & Grading ROI, Interactive Valuation Explainability & Collectibility Thesis, Hierarchical Containers, Multi-Platform CSV Migration Wizard (CoinSnap, Numista, PCGS/NGC, spreadsheets with SSRF-safe photo import), Multiple Vaults & Shared RBAC Vaults (`OWNER`/`EDITOR`/`VIEWER` with Owner-backed BYOK inheritance), Offline Coin-Show PWA Mode, CSV/JSON/Print Insurance Exports, and Global Operator Admin.
    - Present the four-tier SaaS plan matrix aligned with `tiered-access` (`Collector Vault (Free)` `$0/mo`, `Plus` `$9.99/mo`, `Unlimited` `$19.99/mo`, `Dedicated Server` `$99.99/mo`) alongside a clear **Self-Hosted / Open Source** (`Docker Compose` & `Kubernetes` with `BILLING_ENFORCE_TIERS=false`) deployment callout, while preserving existing `"Collector Vault (Free)"` test compatibility.
  - Add interactive product capability explorer tabs, transparent FAQ accordion, mobile navigation drawer, and enterprise trust/legal pages (`/security`, `/privacy`, `/terms`) with frontend-only CTAs (`/register`, `/login`, `mailto:` / GitHub).
- **Technical SEO, Build-Time Prerendering, Social Sharing & Edge Delivery (`seo-social-and-edge-delivery`)**:
  - Add dynamic per-route SEO metadata management (`<title>`, `<meta name="description">`, `<link rel="canonical">`, `robots` directives including `noindex, nofollow` on private/auth routes `/login`, `/register`, `/invite/*`, `/collection`, `/scan`, etc.) plus JSON-LD structured data (`SoftwareApplication`, `Organization`, `WebSite`, `FAQPage`).
  - Add build-time static HTML prerendering during `npm run build` so search engines and zero-JS social crawlers receive full semantic HTML, route-specific `<head>` metadata, and Open Graph / Twitter Card tags for `/`, `/marketing`, `/features`, `/pricing`, `/security`, `/privacy`, `/terms`, and `/coming-soon`.
  - Generate and serve `/robots.txt`, `/sitemap.xml`, and a crisp raster `1200x630` `/og-image.png` (alongside Open Graph `og:*` and Twitter `twitter:card="summary_large_image"` meta tags) plus an accessible Web Share / copy-link action.
  - Harden `frontend/nginx.conf` and `frontend/vite.config.ts` for enterprise production delivery: security headers (`X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`, `Permissions-Policy`, `Content-Security-Policy`), `server_tokens off`, gzip compression, differentiated `Cache-Control` (immutable hashed assets vs. `no-cache` HTML/SW/crawler files), non-redirecting clean-URL static serving, and Workbox `navigateFallbackDenylist` for `/robots.txt`, `/sitemap.xml`, `/api/`, `/super-admin/`, and `/media/`.
- **Comprehensive Automated Test Coverage**:
  - Add Vitest + build/config verification tests covering all public pages/routes, interactive controls, accessibility landmarks, SEO/social meta management, JSON-LD payload validation, prerendered HTML output verification, `robots.txt`/`sitemap.xml`/`og-image.png` presence, and `nginx.conf` directives while keeping full compatibility with the `100%` frontend coverage threshold.

## Capabilities

### New Capabilities
- `public-marketing-website`: Public-facing Stacker Stash front website (`/` default marketing experience, `/features`, `/pricing`, `/security`, `/privacy`, `/terms`, `/coming-soon`), complete asset and capability showcase, 4-tier SaaS + self-hosted pricing presentation, interactive showcase/FAQ, responsive mobile navigation, and trust/legal disclosure pages.
- `seo-social-and-edge-delivery`: Technical SEO (`index.html`, per-route meta/canonical/robots management, JSON-LD, `robots.txt`, `sitemap.xml`, build-time static HTML prerendering), Social sharing readiness (Open Graph, Twitter Cards, `1200x630` `og-image.png`, share action, canonical `"Stacker Stash"` branding), and production Nginx security/compression/caching/PWA fallback isolation.
