# Proposal

## Why

New collectors and self-hosters need clear onboarding documentation, migration instructions for CoinSnap/Numista/PCGS/NGC, and operational how-tos (BYOK keys, Live Spot copper math, and Django Admin setup) directly in the repository.

## What Changes

- Add `docs/USER_GUIDE.md` covering Vault creation, Live Spot auto-refresh and Copper (`HG`) normalization, Vision AI scanning, the CSV Migration Wizard, hierarchical containers, appraisals/cert verification, BYOK Settings, and Django Admin superuser setup.
- Expand `README.md` with full feature coverage, Docker Compose & local development quickstarts, testing commands, and links to the User Guide and OpenSpec changes.

## Capabilities

### New Capabilities
- `user-documentation`: End-user onboarding guide, platform migration how-tos, and operator setup documentation.

### Modified Capabilities
- None.

## Impact

- `README.md`
- `docs/USER_GUIDE.md`
